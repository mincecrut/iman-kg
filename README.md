# Иман — ислам сайты (кыргызская версия)

Статический сайт без сборки, весь интерфейс на кыргызском языке. Работает на GitHub Pages.

## Что внутри

- **Куран**: 114 сүрө, арабский текст (Усмани), кыргызский перевод Шамсуддина Хакимова (источник QuranEnc.com, со сносками), чтение вслух (Мишари аль-Афаси), закладки, «Улантуу», режим заучивания, озвучка аята с повтором, отметка «Жатталды», «поделиться аятом», поиск по тексту перевода, цель чтения и серия дней.
- **Тафсир** по нажатию 📖 у аята: ат-Табари (на арабском, spa5k/tafsir_api). Кыргызского тафсира в открытом виде найти не удалось.
- **Алфавит**, **викторина**, **тасбих**, **зикры**, **дуа**, **99 имён Аллаhа**, **пять столпов**, **каналы**.
- **Офлайн и установка на телефон** (PWA).

Русская версия сохранена отдельным архивом `iman-site-ru.zip` (в сайт не входит).

## Перевод на кыргызском: важно

Перевод берётся с QuranEnc.com (ключ `kyrgyz_hakimov`). Лицензия QuranEnc: текст нельзя менять (поэтому в переводе остаётся «Аллах», а не «Аллаh»), нужно указывать источник и версию, сноски сохранять. Источник указан на странице.

Браузерный доступ (CORS) к API QuranEnc я проверить не смог, поэтому лучше положить перевод на сайт:

```bash
python3 tools/fetch_kyrgyz.py
```

Скрипт скачает 114 файлов в `data/ky/` (+ `_meta.json` с датой). Загрузите папку `data/` в репозиторий вместе с сайтом: тогда сайт берёт перевод со своего адреса, а API QuranEnc остаётся запасным вариантом. После скачивания проверьте, что в конце написано «6236 аят».

## Как выложить на GitHub Pages

1. Создайте репозиторий (например, `iman`).
2. Загрузите `index.html`, `style.css`, `script.js`, `manifest.json`, `sw.js`, `README.md`, `icon-192.png`, `icon-512.png` (и папку `data/`, если скачали перевод; `tools/` по желанию).
3. **Settings → Pages → Deploy from a branch**, ветка `main`, папка `/ (root)`.

### Через Termux

```bash
pkg install git
git init
git add .
git commit -m "Иман"
git branch -M main
git remote add origin https://github.com/<ник>/<репозиторий>.git
git push -u origin main
```

## Обновление сайта

После изменения файлов увеличьте номер в `sw.js`: `const VERSION = "iman-v18"` → `iman-v19`, иначе телефоны покажут старую версию.

## Защита страницы

В `index.html` включён CSP: страница обращается только к `api.alquran.cloud`, `api.aladhan.com`, `cdn.islamic.network`, `cdn.jsdelivr.net`, `quranenc.com` и Google Fonts. Новый внешний сервис нужно добавить в политику.

## Проверка текстов

Кыргызские тексты (интерфейс, значения 99 имён, викторина, названия сур, описания букв, дуа) написаны мной, их должен проверить носитель языка и знающий человек.
